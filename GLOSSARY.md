# Activity Library

The personal activity-history area of Trip Animator. The English product name is provisional.

## Language

**Activity Library**:
A user's private collection of sporting activities, explored through search, a map, and statistics.
_Avoid_: Atlas, import screen

**Historical Import**:
The initial collection of a user's available activity history from a connected provider.
_Avoid_: Import all (when only a bounded batch is imported)

**Library Activity**:
A single sporting session in a user's activity history, whether or not it has a geographic track or is used in a trip. Using it in several projects does not create additional library activities.
_Avoid_: Trip, stage

**Atlas**:
The view of curated trips and journeys prepared in the portal, rather than the user's entire sporting history.
_Avoid_: Activity Library, training history

**Project-local Split**:
A division of an activity's material into segments for one trip or animation project. It does not divide the library activity or change its use in other projects.
_Avoid_: Splitting the library activity

## Trip Playback

**Cinematic Photo Stop**:
A moment in a trip film when the route marker stops, the map zooms in and gives way to one or more full-frame photos, and the journey resumes after the return to the map.
_Avoid_: Cinematic Ken Burns (a photo card style)

**Photo Group**:
A sequence of route photos shown in a single Cinematic Photo Stop because each consecutive pair is within the chosen marker travel-time threshold.

## Render Execution

**Render Backend**:
A pluggable execution target responsible for turning a queued render job into an output video and thumbnail.
_Avoid_: Worker mode, cloud flag, render driver

**Render Bundle**:
An immutable, self-contained package of a serialized render manifest and its required photo assets staged for a remote render backend.
_Avoid_: Job payload, render zip, manifest dump

**Remote Execution**:
A single backend-managed render run tracked against a render job via an opaque backend reference.
_Avoid_: Lambda job, cloud task, pipeline run

## Rendering & Credits

**Local Export**:
An MP4 trip film rendered directly in the user's browser without server compute or credit consumption.
_Avoid_: Client render, browser render

**Server Render**:
An asynchronous MP4 trip film generated by backend rendering infrastructure and billed in Render Credits.
_Avoid_: Cloud export, backend render

**Render Credit**:
A prepaid usage unit spent to run a Server Render, proportional to the render's output parameters.
_Avoid_: Token, coin, render point

**Credit Voucher**:
A redeemable code that grants a fixed amount of Render Credits to a user's balance.
_Avoid_: Invite code, promo token, coupon

**Credit Ledger**:
An append-only record of all Render Credit grants, debits, refunds, and manual adjustments from which a user's balance is derived.
_Avoid_: Credit counter, wallet table, balance log

## Map

**Marked Trail**:
A hiking, cycling or MTB trail that is signposted in the terrain and recorded in OpenStreetMap as a named or numbered route, shown on the map as context for a trip.
_Avoid_: Outdoor Trail, route (reserved for the user's own track), path
